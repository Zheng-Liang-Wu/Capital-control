# 資金管控儀表板

直接在 Google 試算表手機 App 或瀏覽器填寫「目前資金快照」；GitHub Pages 前端讀取試算表 CSV，展示總本金、倉位投入金額、占比及現貨 70% 下限。

## 試算表欄位

在工作表第 1 列建立以下欄位標題；每次本金或任一倉位變動後，在最底下新增一列，填寫**目前完整狀態**，而非單筆異動：

1. 日期
2. 總本金
3. 現貨金額
4. 長線合約金額
5. 趨勢合約金額
6. U倉金額

金額欄填純數字，不要把幣別文字一起放進儲存格。`config.js` 中已先放入使用者提供的試算表連結（gid=0）；若要改用其他工作表，請更改該網址中的 gid。

## 試算表與資料發布

儀表板讀取最後一列資料，頁面載入後每 30 秒自動同步，也可以按右上角「更新」立即讀取；切回頁面時也會同步。因為 GitHub Pages 是公開靜態前端，需讓前端匿名讀取試算表：可以在試算表「共用」中將一般存取設為「知道連結的任何人－檢視者」。也可選擇「檔案 → 共用 → 發布到網路」只發布需顯示的工作表。設定 `CURRENCY` 為顯示單位，例如 `USDT` 或 `TWD`。

> GitHub Pages 是公開網站。發布試算表 CSV 後，知道網址的人都可能讀取帳務數字。若不接受公開，請勿發布 CSV；改用登入保護的資料服務（例如需 Google 登入的後端），不要將私密憑證寫進前端。

## GitHub Pages

repository 已設定為從 `main` 分支根目錄發布 GitHub Pages。之後推送前端檔案到 `main`，GitHub Pages 會自動重新建置；試算表資料則由前端每 30 秒同步一次。

## 計算方式

- 總本金是已入金的 USDT；畫面直接呈現本金及現貨、合約長線、合約波段、U 倉四類金額。
- 各倉位占比 = 該倉手動填報金額 ÷ 總本金。
- 尚未分配 = 總本金 − 現貨 − 長線合約 − 趨勢合約 − U 倉。
- 現貨提示以現貨金額 ÷ 總本金判斷是否達到 70%。
- U 倉會額外顯示台幣估值，按 `config.js` 的 `USDT_TWD_RATE` 換算；目前預設約 NT$31.8 / USDT，匯率可自行修改。
- 只記錄總本金和各倉配置金額，不追蹤未實現損益或交易。

前端未設定試算表時會顯示示範資料，並清楚標示「範例資料」。
